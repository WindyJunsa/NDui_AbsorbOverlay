# NDui Absorb Overlay

Lightweight plugin for [NDui](https://github.com/siweia/NDui) that makes absorb shields on raid/party frames easier to read — especially at full HP.

## Features

- Missing-health absorbs still grow from current HP to the right (NDui default).
- Overflow / full-HP shields show as black dashed lines from the left.
- Custom sparse dash texture for contrast on class-colored health bars.
- Does not recolor class health bars or patch NDui files.

## Requirements

- NDui
- WoW Retail (Midnight / matching NDui TOC)

## Install

1. Enable **NDui**
2. Enable **NDui Absorb Overlay**
3. `/reload`
